# Oprhus AV Scanner Unified 0.2 beta

**Легкий, високопродуктивний і повністю автономний антивірусний сканер для Linux**, написаний на чистому Bash.

Розроблений за принципом **BusyBox-first** — працює майже на будь-якій системі з мінімальними залежностями (навіть на мінімальних контейнерах, VPS та вбудованих пристроях).

> Один файл. Нуль зовнішніх залежностей для базової роботи. Максимальна переносимість.

---

## Ключові можливості

- **Оновлення сигнатур** (`-u`) — Maldet, ClamAV, YARA, MalwareBazaar + власні кастомні бази
- **BusyBox-first** — автоматично шукає/завантажує статичний busybox і використовує його для хешування, `find`, `grep`, `awk`, `strings` тощо
- **Паралельні воркери** — пакетне хешування (SHA256 + MD5) + пакетне YARA-сканування
- **Строгий контроль RAM** (Zero-RAM lookup + RAM Ceiling) — безпечно працює навіть на слабких VPS
- **Живий моніторинг** — RAM / CPU / ETA / FPS у реальному часі
- **Глибока евристика**:
  - рядки + hex-ERE
  - base64-пейлоади
  - замасковані файли (magic-bytes)
  - SUID/SGID
  - перевірка цілісності системних бінарників через dpkg/rpm
- **Сканування архівів** (`-A`) — zip, tar, gz, bz2, xz, 7z, rar з захистом від zip-бомб і розпакуванням у `/dev/shm`
- **Карантин** (`-q`) — автоматичне переміщення загроз із безпечними правами (0400)
- **Режим реального часу** (`-w`) — фоновий демон (inotifywait або polling)
- **Інкрементальне сканування** (`-I`) — пропускає незмінені файли
- **Повністю самодостатній** — усе в одному файлі (включно з воркером)

## Швидкий старт

```bash
# 1. Зробити виконуваним
chmod +x orphus-av.sh

# 2. (Рекомендовано) Встановити busybox + yara
./orphus-av.sh --setup

# 3. Перевірити залежності
./orphus-av.sh --check-deps

# 4. Оновити сигнатури
./orphus-av.sh -u

# 5. Запустити сканування
./orphus-av.sh -d /var/www

# Глибоке сканування з архівами + карантином
./orphus-av.sh -d /home -A -q

# Режим реального часу (після початкового скану)
./orphus-av.sh -d /var/www -w --low-priority
```

## Основні опції

| Опція | Опис | За замовчуванням |
|-------|------|------------------|
| `-d, --dir PATH` | Директорія для сканування | `/mnt` |
| `-u, --update` | Оновити сигнатури і вийти | — |
| `-q, --quarantine` | Увімкнути карантин | `./quarantine` |
| `--quarantine-dir PATH` | Власна директорія карантину | — |
| `-o, --output FILE` | Файл звіту (пишеться live) | `./av_scan_threats_<timestamp>.log` |
| `-r, --max-ram MB` | Ліміт RAM | `500` |
| `-j, --workers N` | Кількість воркерів | auto |
| `-m, --max-size MB` | Макс. розмір файлу для глибокого аналізу | `10` |
| `-X, --exclude PATH` | Виключити шлях (можна кілька разів) | — |
| `-A, --scan-archives` | Сканувати архіви | вимкнено |
| `-w, --real-time` | Режим моніторингу в реальному часі | вимкнено |
| `-I, --incremental` | Інкрементальне сканування | вимкнено (авто при `-w`) |
| `--verify-suid` | Перевірка SUID/SGID через dpkg/rpm | вимкнено (авто при `-w`) |
| `--low-priority` | Мінімальний пріоритет CPU/IO | вимкнено |
| `--setup` | Встановити/зібрати yara + busybox | — |
| `--check-deps` | Перевірити залежності | — |
| `-h, --help` | Допомога | — |

### Додаткові опції для архівів

| Опція | Опис | За замовчуванням |
|-------|------|------------------|
| `--archive-max-mb N` | Макс. розмір архіву (стиснутий) | `200` |
| `--archive-ram-max-mb N` | Макс. розмір для розпакування в RAM | `50` |
| `--archive-max-extract-mb N` | Ліміт розпакованих даних (захист від zip-бомб) | `500` |
| `--archive-max-depth N` | Глибина вкладених архівів | `2` |
| `--archive-max-files N` | Макс. файлів в одному архіві | `2000` |

## Придушення хибних спрацьовувань

Файл `signatures/ignore_sigs` (створюється автоматично):

```text
# Один ERE-патерн на рядок (порівнюється з "TYPE|info")
rule=WEBSHELL_PHP_Dynamic_Big
pattern=chmod 777
```

## Приклади використання

```bash
# Швидке сканування сайту
./orphus-av.sh -d /var/www/html -j 4 -r 300

# Повне сканування + архіви + карантин + звіт
./orphus-av.sh -d / -A -q -o /var/log/orphus-scan.log

# Фоновий моніторинг з низьким пріоритетом
./orphus-av.sh -d /var/www -w --low-priority -I

# Тільки оновлення баз
./orphus-av.sh -u
```

## Важливо

- Скрипт **не** вимагає root для базового сканування, але для карантину, SUID-перевірки та деяких системних операцій права можуть знадобитися.
- При першому запуску `--setup` може знадобитися компілятор (для збірки YARA) або можливість завантажити prebuilt-бінарники.
- Архівне сканування має реальну ціну по CPU/часу — тому за замовчуванням вимкнене.
