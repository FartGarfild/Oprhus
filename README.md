Oprhus AV Scanner Unified 0.2 betaOprhus AV Scanner — це легкий, високопродуктивний та автономний антивірусний сканер для Linux-систем, написаний на Bash. 
Він розроблений із принципом BusyBox-first для максимальної переносимості між системами без необхідності встановлення складних залежностей.
🛠 Ключові можливостіОновлення сигнатур (-u): Завантаження сигнатур з Maldet, ClamAV, YARA, MalwareBazaar та підтримка користувацьких баз.
Принцип BusyBox-first: Автоматичне використання або завантаження статичного busybox для прискорення обробки файлів та хешування без прив'язки до системного утиліту PATH.
Паралельна обробка: Підтримка багатопотоковості (Workers) для хешування (SHA256, MD5) та пакетного YARA-сканування.
Оптимізоване використання пам'яті (Zero-RAM lookup): Строгий контроль лімітів RAM (RAM Ceiling) для запобігання Out-Of-Memory ситуаціям на слабких VPS.
Глибокий евристичний аналіз:Аналіз за сигнатурами рядків та Hex-ERE.Виявлення декодованих Base64-навантажень.
Виявлення замаскованих розширень файлів (за magic-байтами).Контроль прав доступу (SUID / SGID).Перевірка цілісності системних бінарників через бази dpkg / rpm.
Сканування архівів (-A): Підтримка .zip, .tar, .gz, .bz2, .xz, .7z, .rar із захистом від "zip-бомб" та можливістю розпакування напряму в RAM (/dev/shm).
Моніторинг у реальному часі (-w): Фоновий режим (демон), що відстежує нові файли через inotifywait або фоновий опитувальник (polling).
Ізоляція загроз (-q): Автоматичне переміщення виявлених загроз у карантин із безпечними правами доступу (0400).
Інкрементальне сканування (-I): Кешування перевірених файлів задля пропуску незмінених об'єктів при повторних проходах.
Автономність: Увесь функціонал сканера та локального воркера міститься в одному єдиному файлі.📂 
Структура пакету (Package Layout)Для повноцінної роботи достатньо одного файлу av_scan.sh.

🚀 Швидкий старт та Встановлення
1. Перевірка залежностей та первинне налаштуванняПеред першим запуском ви можете автоматично зібрати або завантажити необхідні компоненти (yara, yarac, grep, busybox):
Автоматична збірка/завантаження необхідних компонентів у ./bin/
./av_scan.sh --setup
2. Перевірка залежностей
./av_scan.sh --check-deps
2. Оновлення баз сигнатур:
./av_scan.sh -u
3. Сканування директорії за замовчуванням (/mnt) або вказаного шляху:
./av_scan.sh -d /var/www/html

# Глибоке сканування з архівами
./av_scan.sh -d /home -A

Пригнічення хибних спрацьовувань (Ignore Sigs)
Якщо певні легітимні файли (наприклад, зашифровані модулі CMS) розпізнаються як загрози, ви можете додати правило у файл signatures/ignore_sigs без редагування баз сигнатур:
Приклад ignore_sigs (формат ERE):
rule=WEBSHELL_PHP_Dynamic_Big
pattern=chmod 777
