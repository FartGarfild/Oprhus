## Signature Update System

Проект використовує **мультиджерельну систему сигнатур** для максимальної детекції при мінімальному споживанні RAM.

### Джерела сигнатур

| Джерело              | Тип даних                     | Розмір (приблизно) | Частота оновлення | Примітки |
|----------------------|-------------------------------|--------------------|-------------------|----------|
| **Maldet Sigpack**   | MD5, HEX, YARA, strings      | ~15–30 MB         | Щоденно           | Найкраще для webshell та Linux malware |
| **ClamAV**           | main.cvd + daily.cvd         | 250–400 MB        | Щоденно           | Потужна класична база |
| **MalwareBazaar**    | SHA256 hashes                | ~5–15 MB          | Кожні 5–60 хв     | Дуже свіжі зразки |
| **YARA Rules**       | Neo23x0 + Yara-Rules         | 50–150 MB         | При оновленні     | Потужні правила поведінки |
| **Custom**           | MD5, SHA256, strings, regex  | < 1 MB            | Ручне             | Твої власні сигнатури |

### Як оновлювати бази

```bash
./update_sigs.sh
```

- Запускай **раз на добу** (рекомендовано по крону вночі).
- Перше оновлення може зайняти 2–5 хвилин (завантаження ClamAV).
- Після оновлення запускай скан: `./av_scan.sh --sigs ./signatures`

### Custom сигнатури

Створи папку `signatures/custom/` і додай файли:

- `custom.md5` — формат `hash\tНазва`
- `custom.sha256` — формат `hash\tНазва`
- `custom.strings` — один патерн на рядок (підтримуються regex)

**Приклад custom.md5:**
```text
50f28383803099955e695f2e825a0a38	Custom.Backdoor
75a74e0626359e933405389656209e51	Custom.Webshell
```

**Приклад custom.strings:**
```text
eval\(base64_decode
PHPDATA.*mbd;
round\((\d+\.?\d*\+?){2,}\)
goto [A-Za-z0-9_]+;
```

### Нюанси та рекомендації

- **RAM**: Скрипт оптимізований під low-memory VPS (batch hashing, zero-RAM lookup, обмеження по RAM).
- **Диск**: ClamAV + YARA займають місце, але це разова вартість.
- **MalwareBazaar**: Потрібен безкоштовний Auth-Key (отримується на сайті).
- **YARA**: Наразі правила збираються, але ще не використовуються в worker (Буде додано в нових версіях).
- **Оновлення**: `update_sigs.sh` можна запускати вручну або по крону.

```bash
# Приклад cron (раз на добу о 3:30)
30 3 * * * /path/to/update_sigs.sh >> /var/log/av_update.log 2>&1
```
